アバター（Anam）にクローンした声で喋らせる手順
====================================================

全体の流れ
  写真 → [Anam] 顔を作る
  録音 → [Fish Audio] 声を作る（今までの clone と同じ）
  文章 → 声で読み上げ → 顔の口を合わせて別ウィンドウに表示

詳しい説明は docs/avatar.md を見てください。


■ 0. 最初の1回だけ（準備）
----------------------------------------------------
1) voice-clone-proto フォルダでターミナルを開いて、仮想環境に入る
   .venv\Scripts\activate

2) アバター用のパッケージを入れる
   pip install -r requirements-avatar.txt

3) Anam の API キーを .env に入れる（済んでいれば飛ばす）
   https://lab.anam.ai/api-keys で「Create API key」→ 表示されたキーをコピー
   .env の「ANAM_API_KEY=」の後ろに貼って保存
   ※キーは作ったときしか表示されない。なくしたら作り直す


■ 1. Anam だけ動くか確認する
----------------------------------------------------
手元の音声ファイルを、サンプルの顔に喋らせる（声のクローンは使わない）
   python voice_clone.py avatar --audio test.mp3

・別ウィンドウに顔が出て、test.mp3 の音声に合わせて口が動けばOK
・ウィンドウの上で q を押すと終わる


■ 2. 写真から顔を作る
----------------------------------------------------
1) 写真を voice-clone-proto フォルダに置く（例: me.jpg）

   写真のコツ
   ・写っているのは1人だけ、18歳以上
   ・正面、明るい場所、肩まで写す
   ・美肌フィルターなどの加工なし（若く判定されて弾かれやすい）
   ・JPEG / PNG / WebP（それ以外や4.5MB超は自動でJPEGに変換）

2) 顔を作る（名前は3文字以上。数十秒かかる）
   python voice_clone.py avatar-create me.jpg --name tako

   「この写真は自分、または本人の同意を得た人の写真ですか？」→ y

3) 作った顔の一覧を見る
   python voice_clone.py avatar-list

   ※写真のチェックは無料プランだと1日10回まで（弾かれた分も数える）


■ 3. 作った顔に喋らせる
----------------------------------------------------
・手元の音声で、作った顔を確認
   python voice_clone.py avatar --audio test.mp3 --face tako

・クローンした声で喋らせる（--voice は clone でつけた名前）
   python voice_clone.py avatar "[嬉しい]こんにちは！来てくれてありがとう。" --voice tako --face tako

・接続したまま、打った文章を次々に喋らせる
   python voice_clone.py avatar --voice tako --face tako -i
   → 「喋らせる文章>」に文章を打って Enter
   → 何も打たずに Enter か q で終わる

・写真から顔を作って、そのまま喋らせる（展示で撮った写真を使うときの形）
   python voice_clone.py avatar "こんにちは！" --voice tako --image me.jpg


■ 4. うまくいかないとき
----------------------------------------------------
・「.env に ANAM_API_KEY がありません」
   → 0-3) をやる

・「アバターを作れませんでした（422）… 18歳以上…」
   → 写真の安全チェックで弾かれた。2-1) のコツを見て撮り直す

・「写真チェックの回数上限です」
   → 1日10回を使い切った。次の日に試す

・顔を作った直後に、喋らせるとエラーになる
   → Anam 側で準備中。少し待ってからもう一度

・q を押しても終わらない（-i で文章入力を待っているとき）
   → ターミナルで Enter も押す

・口と音がずれる / 映像がカクつく
   → ネットワークが遅い可能性。有線LANか、別の回線で試す


■ 注意
----------------------------------------------------
・顔写真も声も、本人の同意を得たものだけを使う
・Anam はアバターにつないでいる時間で料金がかかる（Fish Audio の料金は別）
・.env（APIキー）、voices.json、avatars.json は GitHub に上げない（.gitignore 済み）
