# 喋り方の調整（speech-style）

LLM の返答を、音声合成に渡す前に「喋りやすい形」に整えます。
棒読み・抑揚がない・イントネーションがおかしい、への対策です。

```
LLM の返答 → [喋り方の調整] → 音声合成（Fish Audio）
```

## やっていること

| 処理 | 内容 | 例 |
|---|---|---|
| 掃除 | マークダウン・絵文字・顔文字・URL を消す | `**ようこそ！**😊` → `ようこそ！` |
| 伸ばし棒 | ひらがなの後ろの「ー」「〜」を母音に置き換える（カタカナ語はそのまま） | `やったー` → `やったあ`、`ラーメン` → `ラーメン` |
| 文に区切る | 。！？ と改行で区切る（`！？` は1つの区切りとして扱う） | |
| 息継ぎ | 読点なしで25文字以上続く文に、「ので」「けれど」などの後ろで読点を足す | `雨だったので来る人が…` → `雨だったので、来る人が…` |
| 感情タグ | 日本語タグを英語に直し、文頭に寄せ、1文3つまでにする | `今日は[嬉しい]晴れ！` → `[happy] 今日は晴れ！` |
| アクセント | 辞書に登録した単語を、高低指定タグに置き換える |
| 漢字の連続 | 漢字が4文字以上続く部分を、ひらがなに置き換える（中国語と間違われないように） | `豚角煮丼好評販売中` → `ぶたかくにどんこうひょうはんばいちゅう` | `HAL` → `<\|phoneme_start\|>ha1ru0<\|phoneme_end\|>` |

## コマンド

```bash
# 整えた結果を見るだけ（無料・API を使わない）
python voice_clone.py style "**ようこそ！**😊 [嬉しい]今日は来てくれてありがとう。"

# 整えてから、作った声で読み上げる
python voice_clone.py speak "[嬉しい]今日は来てくれてありがとう！" --voice tako

# 単語の高低を自動推定する（辞書づくり用）
python voice_clone.py accent 橋が 箸が 端が
```

| オプション | 内容 |
|---|---|
| `--no-emotion` | 感情タグを全部消す（タグあり/なしの聴き比べ用） |
| `--auto-emotion` | タグのない文に、文末の `！` `！？` から自動でタグを付ける |
| `--no-pauses` | 読点を足さない |
| `--long-vowel vowel/keep/drop` | ひらがなの後ろの伸ばし棒の扱い（既定: vowel） |
| `--compare-long-vowel` | `speak` で、伸ばし棒の扱いを3通り作って聴き比べる |
| `--kanji hiragana/phoneme/off` | 漢字が長く続く部分の扱い（既定: hiragana） |
| `--kanji-min-run 数` | 漢字が何文字続いたら置き換えるか（既定: 4） |
| `--compare-kanji` | `speak` で、漢字の扱いを3通り作って聴き比べる |
| `--tries 数` | 同じ設定で何回作るか（たまにしか起きない問題を確かめる用） |
| `--dict パス` | アクセント辞書を指定（既定: `accent_dict.json`） |
| `--file パス` | 文章をテキストファイルから読む |

`speak` は `say` と同じく `--temperature` `--speed` `--model` なども使えます。

## 伸ばし棒

「やったー」「すごーい」のように、ひらがなの後ろの伸ばし棒は音声合成が苦手で、イントネーションが崩れやすいです。
既定では母音に置き換えます（`やったー` → `やったあ`）。カタカナ語（ラーメン・コーヒー）は正しい書き方なので触りません。

| モード | やったー | すごーい | うんー |
|---|---|---|---|
| vowel（既定） | やったあ | すごおい | うん |
| keep | やったー | すごーい | うんー |
| drop | やった | すごい | うん |

どれが一番自然かは声によって変わるので、聴き比べて決めてください。

```bash
python voice_clone.py speak "やったー！すごーい、ほんとにー？" --voice tako --compare-long-vowel
# → output/speak_日時_vowel.mp3 / _keep.mp3 / _drop.mp3 ができる
```

## アクセント辞書（accent_dict.json）

```json
{
  "_説明": "_ で始まるキーは無視される（メモ用）",
  "HAL": "ha1ru0",
  "箸": "auto"
}
```

- 手書き: 母音（a i u e o）・ん（N）・っ（cl）の後ろに、高い=1 / 低い=0 を付ける
- `auto`: 自動推定。`pip install -r requirements-style.txt` が必要
- 自動推定は Fish Audio 公式の例（橋が=ha0shi1ga0、箸が=ha1shi0ga0、端が=ha0shi1ga1）と一致することをテストで確認済み

### 辞書に入れるべき単語

全部の単語を入れる必要はありません。**実際に読ませてみて、おかしかった単語だけ**登録します。

1. `speak` で読ませて、イントネーションが変な単語を見つける
2. `accent その単語` で自動推定を見る
3. 推定が合っていれば `"単語": "auto"`、違っていれば数字を手で直して登録する

固有名詞（学校名・人名・アプリ名）や英語の略語は、最初から登録しておくと安全です。

## LLM 担当に渡すもの

感情タグと話し言葉は、LLM に最初からその形で出させるのが一番自然です。
指示文の案は `docs/llm-prompt.md` にあります。ここの処理は、その出力の「保険」として後から整える役割です。

## 日本語なのに別の言語（中国語など）で読まれるとき

**原因: 漢字ばかりの文。**「吉野家の豚角煮丼好評販売中」は92%が漢字で、ひらがなは「の」だけです。
音声合成からは日本語か中国語か区別がつかず、生成のたびのランダムさで、たまに中国語になります。

**対策:** 漢字が4文字以上続く部分を、ひらがなに置き換えます（既定でオン、pyopenjtalk-plus が必要）。

| モード | 豚角煮丼好評販売中 |
|---|---|
| hiragana（既定） | ぶたかくにどんこうひょうはんばいちゅう |
| phoneme | `<\|phoneme_start\|>bu0ta1ka1ku0...<\|phoneme_end\|>`（アクセント指定タグ） |
| off | 豚角煮丼好評販売中（そのまま） |

たまにしか起きない問題なので、各モードを何回か作って確かめてください。

```bash
python voice_clone.py speak "吉野家の豚角煮丼好評販売中！" --voice tako --compare-kanji --tries 3
# → hiragana / phoneme / off × 3回 = 9ファイルできる
```

- 読みを間違える単語は `accent_dict.json` に登録すると、そちらが優先されます
- Fish Audio の「文章正規化（normalize）」はオンのままにしてください。オフにすると日本語で読まれなくなりました（`--no-normalize` は付けない）
- LLM 側でも、漢字ばかりの文にならないよう話し言葉で返してもらうのが一番の予防です

## 注意

- 読点を足す処理は簡易的なルールです。不自然なら `--no-pauses` で比べてください
- 感情タグは自由な英語でも書けます（Fish Audio の仕様）。日本語タグは対応表（`voice/speech_style/emotion.py` の `JA_TO_EN`）にあるものだけ英語に直し、それ以外は外します
- タグを付けすぎると不安定になるので、全文に付けるより「感情が動く文」だけに付ける方が自然です
